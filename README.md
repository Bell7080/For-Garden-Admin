# For Garden · 운영 콘솔

기존 Supabase 로그인·역할 확인·이미지 보관함을 유지하는 공지 관리 화면입니다.

- 게시 중 / 예약 게시 / 임시저장 현황, 제목·주소 검색, 공지 분류·상태 필터.
- 기본 정보 → 원문·언어별 원고 → 대표 이미지 → 게시 설정으로 나뉜 편집기.
- 공지·업데이트·이벤트 템플릿, 소제목·목록·이미지 작성, 실시간 미리보기.
- 원문과 직접 작성한 언어별 원고만 저장합니다. 자동 번역 API·버튼·생성 작업·캐시 조회는 없습니다. 다른 언어 원고가 없으면 홈페이지에서 원문을 표시합니다.
- 원문·게시 설정·수동 원고의 원자적 저장과 동시 편집 보호. DB 업데이트 전에는 기존 한국어·영어·일본어 저장 호환 모드를 유지하며 한계를 안내합니다.
- 장치 설정 / 다크 / 라이트, 커스텀 선택 UI·스크롤바·확인창, 실제 게임 폰트, 최소 12px.
- 로그인 토큰은 메모리에 유지. owner/operator만 저장, cs/viewer 읽기 전용. DB RLS가 최종 권한을 판단합니다.

```sh
npm ci
npm run dev   # 5175, 정적 화면
npm test      # 수동 원고 저장·권한·Postgres 트랜잭션·본문 렌더링
npm run check
npm run build # Vercel 정적 배포용 dist/
```

Node 22 이상을 사용합니다. 로그인은 기존 Supabase 이메일/비밀번호·admin_roles 설정을 사용하며 로컬 서버가 이를 모의하지 않습니다. Admin에는 별도 서버용 번역 환경 변수나 외부 번역 계정이 필요 없습니다.

[공지 운영 안내](docs/notice-operations.md)에 수동 작성용 DB 마이그레이션, 기존 스키마 호환과 과거 번역 설정 정리 범위를 기록했습니다. 운영 DB 삭제와 외부 클라우드 리소스 변경은 수행하지 않았습니다.
