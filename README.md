# For Garden · 운영 콘솔

최신 기존 어드민의 로그인·역할 확인·이미지 보관함을 유지하면서 공지 작성 흐름을 정리했습니다.

- 게시 중 / 예약 게시 / 임시저장 현황, 제목·주소 검색, 공지 분류·상태 필터.
- 기본 정보 → 원문·언어별 원고 → 대표 이미지 → 게시 설정 → 번역 현황으로 나뉜 편집기.
- 공지·개발 업데이트·이벤트 템플릿, 소제목·목록·이미지 작성과 독자용 실시간 미리보기.
- 원문 + 게시 설정 + 직접 쓴 번역을 한 번에 저장하고 동시 편집 충돌을 감지하는 RPC.
- 게임과 동일한 한국어 포함 12개 언어. 원문만 작성하면 번역 11개를 준비하고, 읽기 시점에 누락 번역을 생성해 캐시합니다. 직접 쓴 번역이 우선합니다.
- 장치 설정 / 다크 / 라이트 테마, 테마 저장과 장치 변경 반영. 커스텀 선택 UI·스크롤바·확인창, 실제 게임 폰트, 최소 12px.
- 로그인 토큰은 메모리에 유지. owner/operator만 저장·번역, cs/viewer 읽기 전용. DB RLS가 최종 권한을 판단합니다.

```sh
npm ci
npm run dev   # 5175, API와 정적 화면
npm test      # 번역·권한·Postgres 트랜잭션 검증
npm run check
npm run build # Vercel용 dist/; 서버 코드·테스트·설정 파일은 정적 배포에서 제외
```

Node 22 이상을 사용합니다. 로그인은 Supabase 연결이 필요하며 로컬 개발 서버가 이를 모의하지 않습니다. 기존 이메일/비밀번호와 admin_roles 설정을 사용합니다. `.env.local`은 선택적인 서버 API 개발 설정이며 Git에 넣지 않습니다.

DB 마이그레이션과 자체 번역 서버가 아직 연결되지 않은 경우 원문만 표시됩니다. 무료 공개 번역 서버의 무제한 사용을 전제하지 않습니다. 설정·지원 언어·상업 이용 라이선스 범위는 [번역 운영 안내](docs/translation-operations.md)를 확인하세요. 두 Vercel 프로젝트에 서버 전용 환경 변수 설정이 필요합니다.

마이그레이션 전에는 기존 3개 언어의 공지 저장을 유지하는 호환 모드가 동작합니다. 이 모드는 원자적 저장·동시 편집 보호를 제공하지 않으며 화면에 제한을 안내합니다. 추가 언어 저장은 DB 업데이트 후 활성화됩니다.
