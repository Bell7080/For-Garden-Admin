# 운영 일정 — 배너·상품·이벤트를 언제 여는가

어드민 「운영 일정」 화면은 게임의 연구 배너·상품·이벤트·로비 카드가 **언제 열리는지만** 덮어씁니다.
무엇이 나오고 얼마인지(풀·확률·가격·보상)는 지금처럼 게임 정의(코드)가 갖습니다.

## 규칙

- 줄이 없는 항목은 게임 정의에 적힌 기간 그대로 돕니다. 표가 비어 있으면 지금과 똑같습니다.
- 줄이 있으면 그 줄의 시작·종료·켜짐을 따릅니다.
  - 시작·종료를 비우면 그쪽 끝을 **열어 둡니다**(정의 값으로 돌아가지 않습니다).
  - 「켜 둠」을 끄면 기간과 상관없이 닫습니다.
- 「정의 기간으로 되돌리기」는 줄을 지웁니다.
- 배너에 묶인 상품(마일리지 상점의 픽업 SSR 등)은 그 배너가 닫히면 함께 닫힙니다.
  배너로 가는 로비 카드도 배너가 닫히면 내려갑니다.
- 게임 서버는 1분 캐시로 읽어 연구·구매를 같은 기간으로 받아 줍니다. 플레이어 화면은 다음 접속(시작 관문)부터 따라옵니다.

## 고를 수 있는 ID

배포된 게임이 빌드 때 굽는 `https://forgarden.vercel.app/site/schedule.json`(ID·한국어 이름·정의 기간)에서 읽습니다.
목록에 없는 ID도 저장할 수는 있지만 확인을 한 번 더 묻습니다 — 오타는 아무것도 덮지 못한 채 남습니다.

## 권한·기록

- 조회: 모든 운영진 · 고치기: owner·operator
- 감사 로그: `schedule_set` · `schedule_clear` (대상 `live_schedule:<종류>:<ID>`)

## 적용 순서

1. 게임 저장소 `supabase/migrations/20261123000000_live_schedule.sql`
2. 어드민 `supabase/migrations/20261123100000_ops_schedule.sql`

적용 전에는 화면이 "DB 업데이트가 필요합니다"만 띄웁니다.
