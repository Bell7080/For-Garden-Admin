# 정기 운영 (정기 우편 · 패치노트 · 정기 이벤트)

마이그레이션: `supabase/migrations/20261026000000_recurring_ops.sql` (운영 DB 적용은 사람이 확인한 뒤 한 번에).

## 우편 보관기간 무제한
- `mails.expires_at` 이 `null` 이면 만료되지 않는다. 게임 `MailDto.expiresAt: string | null` 은 이미 null 을 무제한으로 읽는다.
- 새 우편 화면의 보관 기간에 「무제한」, `admin_send_mail(..., p_unlimited)`.

## 정기 우편 (아침·점심·저녁·핫타임)
- 우편 탭의 「정기 우편」. 구분(아침/점심/저녁/핫타임/기타)은 화면 분류와 새 항목의 기본값일 뿐 동작은 같다.
- 요일·발송 시각(한국 시간)·보관 시간(무제한 포함)·보상·시작/종료일·신규 가입 계정 포함 여부를 정한다.
- 발송기 `private.run_recurring_mails()` 는 pg_cron 이 매 분 부른다. 하루 한 통(`mails(recurring_id, fire_date)` 유일 색인),
  발송 시각에서 3시간이 지난 회차는 건너뛴다(핫타임이 뒤늦게 나가면 뜻이 없다).
- **pg_cron 이 꺼져 있으면 자동 발송이 돌지 않는다.** Supabase 대시보드 > Database > Extensions 에서 pg_cron 을 켠 뒤
  마이그레이션 끝의 `do $cron$ … $cron$` 블록만 다시 실행한다. 화면은 꺼져 있으면 빨간 경고를 띄운다.
- 만들어진 우편은 일반 우편 목록에도 보이고, 일반 우편처럼 취소·휴지통 처리할 수 있다.

## 패치노트
- 공지 옆 「패치노트」 탭. **1.0.0 정식 출시 이후 버전부터** 기록한다(1.0.0 미만은 DB 가 거절한다).
- 항목은 신규·개선·수정·밸런스·기타 구분 + 한 줄.

## 정기 이벤트
- 「정기 이벤트」 탭: **컨텐츠**(돌림판 1~3형·모래캐기·타로집·대장장이(블랙잭)·기타의 정의: 이벤트 재화 키, 1회 소모량,
  하루 무료 횟수, 가중치 보상표)와 **주간 편성**(월요일 0시 KST 기준 한 주에 하나, 8주 앞까지).
- 게임이 읽는 곳: `get_regular_event()` — 이번 주 컨텐츠(꺼진 것은 제외)와 보상표를 돌려준다.
- 게임 쪽 실제 컨텐츠(돌림판·모래캐기·타로집·블랙잭 대장장이)와 이벤트 재화 지급·소모 경계는 아직 없다.
  이 관리 틀과 DB 구조까지가 이번 범위이며, 컨텐츠 구현은 종류별로 따로 설계·확인 후 진행한다.
