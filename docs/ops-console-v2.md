# 운영 콘솔 v2 (2026-11-06)

메이저 모바일 게임 운영 기준으로 어드민에 비어 있던 자리를 채운 묶음이다. DB 쪽은
`supabase/migrations/20261119000000_ops_console_v2.sql` 하나이며, **2026-11-06 QA와 운영 DB에 적용·검증했다.**
적용 이력과 검증 범위는 [DB 적용 기록](ops-console-v2-applied-2026-11-06.md)에 남겼다.
FAQ 표는 생성됐지만 초기 원고는 없으므로, 운영 콘솔에서 작성·게시한 항목부터 홈페이지에 표시된다.

## 새로 생긴 것

| 화면 | 권한 | 하는 일 |
| --- | --- | --- |
| 대시보드(첫 화면) | 전원 | 누적·오늘 가입·DAU/WAU/MAU·15분 접속, 14일 DAU·신규·D1 잔존, 플랫폼·앱 버전 분포, 미처리 문의·신고·오류·삭제 요청, 점검·진행 중 우편·쿠폰 |
| 클라이언트 오류 | 소유자·운영자 | `client_errors` 목록·필터·검색, 스택·문맥·직전 동작, 상태 변경, 개발자 요약 복사 |
| 권한 관리 | 소유자 | 운영진 목록(이메일·최근 로그인·역할), 이메일로 역할 부여·변경·해제. 자기 자신·마지막 소유자는 막는다 |
| FAQ | 전원 열람, 소유자·운영자 편집 | 홈페이지 문의 페이지 FAQ. 원문 + 영어·일본어 수동 원고(자동 번역 없음) |
| 계정 상세 · 제재 이력 | 소유자·운영자·CS | 그 계정의 상태 변경·삭제·재화 조정 이력과 담당자 |
| 우편 · UID 여러 개 | 소유자·운영자 | UID를 쉼표·줄바꿈으로 여럿 넣으면 계정마다 한 통(최대 1,000), 없는 UID는 돌려준다 |
| 감사 로그 | 소유자·운영자 | 작업 종류·담당자·대상·시작 시각 필터, 100건씩 더 보기 |
| 문의 상세 | — | 신고 대상/작성자 계정 바로 열기 |

일일 활성은 `players.last_seen_at`이 바뀔 때 KST 날짜로 `player_daily_activity`에 한 줄씩 남는다.
적용 시 기존 계정마다 마지막 접속일 한 줄을 채웠고, 그 이전 접속 이력은 복원하지 않는다.
이후 접속부터 일별 기록이 계속 쌓인다.

## 홈페이지(For-Garden-Web)

- `GET /api/faq?lang=` — 게시된 FAQ. 표가 없으면 빈 목록.
- `GET /api/site`에 `maintenance`(`app_config` 점검 메시지·종료 시각) 추가. 문의 페이지 상단에 점검 안내가 선다.
- 문의 페이지 상단에 FAQ(분류별 접기·검색).

## 아직 없는 것(다음 후보)

- 인게임 팝업 배너·푸시 발송 — 게임 쪽 수신부가 먼저 필요하다.
- 닉네임 강제 변경·금칙어 관리.
- 랭킹 기록 제거(부정 기록) · 길드 관리(해산·길드장 이전).
